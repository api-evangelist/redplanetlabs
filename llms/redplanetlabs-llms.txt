# Red Planet Labs — Rama

> Red Planet Labs builds Rama, a unified backend platform that consolidates
> databases, queues, workers, and infrastructure into a single programming model
> for the JVM (Java/Clojure). It aims to reduce backend complexity by up to 100x
> with ACID semantics, reactive queries, and linear scalability.

## Product

- [Rama overview](https://redplanetlabs.com/): the "100X Developer Platform".
- [Programming model](https://redplanetlabs.com/docs/~/tutorial1.html): tutorial.
- [PStates](https://redplanetlabs.com/docs/~/pstates.html): durable, indexed, partitioned state.
- [ACID semantics](https://redplanetlabs.com/docs/~/acid.html): PostgreSQL-comparable transactions.

## API

- [Rama REST API](https://redplanetlabs.com/docs/~/rest.html): POST-only HTTP+JSON RPC surface exposed by Supervisors (default port 2000) for depot appends, PState queries, and query-topology invokes. Base pattern `http://<host>:<port>/rest/<module-name>/...`. No documented authentication (in-cluster surface).
- Conventions: conventions/redplanetlabs-conventions.yml
- Errors: errors/redplanetlabs-problem-types.yml
